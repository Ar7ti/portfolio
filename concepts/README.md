# Concept prototypes

Throwaway prototypes for step 2. Each file shows one concept's signature liquid moment. Open the HTML files directly in a browser, no build step. They load fonts from Google Fonts and (A only) three.js from jsDelivr.

| File | Concept | Try this |
|---|---|---|
| `a-moonshot-stud-tide.html` | A · Moonshot "Stud Tide": 3D sea of studded voxels + Sky Island | Move the cursor through the sea, scroll to send a wave, "Skip the water" for the static version |
| `a2-shrunk-stud-tide-lite.html` | A′ · Shrunk moonshot: side-view voxel sea in one 2D shader | Stir the water, then "Open a case study" for the tsunami wipe |
| `b-realistic-receipts.html` | B · Realistic "Receipts": ink metaballs | Hover or Tab to a claim: ink drips into its receipt |
| `c-fallback-patch-notes.html` | C · Fallback "Patch Notes": CSS + SVG goo, no WebGL | Scroll: the orange drop melts from version to version |

`previews/` has screenshots (desktop 1440×900 and mobile 390×844), taken headless.

All prototypes respect `prefers-reduced-motion` and keep the hero as plain HTML under the effect. Copy is a draft; the real copy comes from `plan/COPY.md`.
